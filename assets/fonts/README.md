Fonts: Didact Gothic (the display face, `--display`), Yellowtail (the script face, `--script`) and Monoton (capitals in parallel lines like ROLLING on the title sign, `--lines`), all under the SIL Open Font License (the OFL-*.txt files). A Roller's sign can set its name and its class in any of the three (Build mode › Neon, `nameFont` and `clsFont`). To change a typeface, replace its `.woff2` here and update `css/fonts.css` and `FONTS` in `js/content/assets.js`.
